This note is a living demo of the writing components available across the garden. **Delete it whenever you like** — it's just here so you can see the syntax and the result side by side.

## Sidenotes

Sidenotes float into the right margin on wide screens and collapse inline on mobile.<Sidenote n={1}>Like this — a margin note that doesn't break your reading flow. Resize the window to watch it move.</Sidenote> Use them for asides, citations, or definitions you don't want cluttering the main line.

```mdx
Some claim.<Sidenote n={1}>The aside goes here.</Sidenote>
```

## Years ago

I started this blog back in <Y y={2023} />, and first learned to code around <Y y={2019} />. The little superscript updates itself every year.

```mdx
back in <Y y={2023} />
```

## Paper texture image

Apply Paper Design's paper texture shader to an image with a one-line component. The original image remains as a fallback when JavaScript or WebGL is unavailable.


## Reference callout

Cite an external article, paper, or link as a prominent card:

<Reference
  href="https://example.com"
  title="Revealed: How the UK tech secretary uses ChatGPT for policy advice"
  author="The Guardian"
  source="archive.is"
/>

```mdx
<Reference href="https://…" title="Headline" author="Author" source="Site" />
```

## Verse

A clean, centred scripture card — the verse in the display serif, a short rule, then the reference beneath it. Borderless and quiet, so a single line reads like an inscription. Pass `reference` and an optional `translation`.

<Verse reference="Romans 3:12">
There is no one righteous, not even one.
</Verse>

```mdx
<Verse reference="Romans 3:12" translation="NIV">
There is no one righteous, not even one.
</Verse>
```

## Coming soon

Mark an unfinished post so readers know it's still growing:

<ComingSoon />

```mdx
<ComingSoon note="Optional custom message." />
```

## Under development

Mark a post you're **still writing**. It mirrors *Coming soon*, but everything after it
is dimmed so readers know the rest is a rough draft (the demo below is wrapped in a box
so only it is affected):

<div class="rounded-sm border border-white/10 p-5">

This sentence is finished and crisp.

<UnderDevelopment />

This sentence sits *after* the marker, so it renders faded — the in-progress signal.

</div>

```mdx
Polished writing up to here.

<UnderDevelopment note="Optional custom message." />

Everything below renders dimmed until you remove the marker.
```

## Two images side by side

Place images in a row, **each with its own caption**. Children are regular `<Figure>`s, so they keep their natural aspect ratio and collapse to one column on mobile.

<ImageGrid>
  <Figure src="/posts/04032024_tokenizer/images/specialtokens.jpg" alt="special tokens">Left image — its own caption sits right underneath.</Figure>
  <Figure src="/posts/04032024_tokenizer/images/gpt4specialtokens.jpg" alt="gpt4 tokens">Right image — captioned independently of its neighbour.</Figure>
</ImageGrid>

```mdx
<ImageGrid>
  <Figure src="/left.jpg" alt="">Caption for the left image.</Figure>
  <Figure src="/right.jpg" alt="">Caption for the right image.</Figure>
</ImageGrid>
```

Pass `cols={3}` for a three-up row.

## Icon list

Swap plain bullets for a small hand-drawn marker. Wrap a normal markdown list; choose `icon="arrow"` (default), `"leaf"`, `"spark"`, or `"star"`.

<IconList icon="leaf">
- Each item gets a cyan marker instead of a bullet.
- Use it for examples, principles, or anything you want to feel considered.
- The markers are masked SVGs, so they pick up the accent colour automatically.
</IconList>

```mdx
<IconList icon="leaf">
- First point.
- Second point.
</IconList>
```

## Feature card

A bordered card for a quote, neologism, or definition — with an optional title and a `From:` attribution. Pass `align="center"` to centre it; nest a `<Tweet/>` inside to feature a post.

<Card title="Brahmin Left" from="Thomas Piketty" fromHref="https://example.com">
The educated, professional wing of left-leaning politics — distinguished from the
working-class base it historically represented.
</Card>

```mdx
<Card title="Term" from="Source" fromHref="https://…">
The definition or quote goes here.
</Card>
```

## Tweet

Embed a post by passing its full URL. Renders the standard embed (a plain link is the no-JS fallback); works on its own or inside a `<Card/>`.

```mdx
<Tweet url="https://twitter.com/user/status/1234567890" />
```

## Video card

A compact "watch this" card — a YouTube thumbnail on the left, the title and source on the right. The whole card links to the video. Pass the YouTube `id`; the thumbnail and link are derived from it.

<VideoCard
  id="-kp3h1Vc9wo"
  title="Dug Up and Fed up: What's Really Happening To Mumbai's Roads"
  source="Times of India | I Witness"
/>

```mdx
<VideoCard id="-kp3h1Vc9wo" title="Video title" source="Channel name" />
```

## Short card

A sidenote-style card for a YouTube **Short** — a small vertical thumbnail that floats into the right margin, with the title and source below. Place it **inline** at the end of a sentence so the prose wraps around it. Pass `ref` to drop a matching marker in the text and on the card: a bare `ref` shows the crimson play glyph; a value (e.g. `ref={1}`) shows that number/symbol instead.

This sentence carries a Short out into the margin, like a video footnote.<ShortCard ref id="bQV3zAq9cmA" title="BMC vs Mumbai Roads" source="Azeem Banatwalla" />

```mdx
…the end of a sentence.<ShortCard
  ref
  id="bQV3zAq9cmA"
  title="Short title"
  source="Channel name"
/>
```

## Book

A book reference — cover, title, author, and an optional description. With a description it lays the cover beside the text; add `small` for a compact, centred card you can stack into a reading list.

<Book
  cover="/now/hard-things.jpg"
  title="Metaphors We Live By"
  author="George Lakoff & Mark Johnson"
  href="https://example.com"
>
The book that started the conceptual-metaphor field — argues that metaphor isn't decoration but the machinery of thought.
</Book>

```mdx
<Book cover="/cover.jpg" title="Title" author="Author" href="https://…">
A sentence or two on why it's worth reading.
</Book>

<Book cover="/cover.jpg" title="Title" author="Author" small />
```

## Aside

A small labelled box for framing notes the reader should see before diving in. It defaults to an **Assumed Audience** label; pass a custom `label` for a caveat, an epistemic-status line, or any other aside.

<Aside>
People who've felt the pull of a digital garden but aren't sure how one differs from a blog. Some familiarity with the open web is assumed.
</Aside>

```mdx
<Aside>
Who you're writing this for.
</Aside>

<Aside label="Epistemic status">
Thinking out loud — expect this to change.
</Aside>
```

## Collapsible sections

Tuck supporting detail behind a tidy accordion. **`Details`** is the neutral one; **`Excursion`** is a warmer "side trip" with an `anchor` for deep links. Both open and close without JavaScript.

<Details title="What's inside a Details block?">
Anything you like — lists, code, images, more components. It stays closed until the reader opens it, so it's perfect for reference material that shouldn't crowd the main flow.
</Details>

<Excursion title="A short detour" anchor="styleguide-detour">
`Excursion` reads as a gentle digression rather than a plain disclosure. Give it an `anchor` and you can link straight to it.
</Excursion>

```mdx
<Details title="Show the details">
  Hidden until the reader opens it.
</Details>

<Excursion title="A worthwhile tangent" anchor="my-tangent">
  A softer, set-apart side trip.
</Excursion>
```

## Scroll-synced presentation

Turn a slide deck into an *annotated talk*: the slides stay pinned on one side while your notes scroll past on the other, crossfading to the matching slide. On a phone each slide simply sits above its note.

Export your slides as images into `public/posts/<slug>/slides/`, then wrap one `<Slide>` per slide inside `<ScrollSlides>`. Each `<Slide>` holds its image and the running notes that belong beside it.

```mdx
<ScrollSlides>
  <Slide image="/posts/my-talk/slides/01.png" alt="Title slide">
    What I said while this slide was up. **Markdown works here.**
  </Slide>
  <Slide image="/posts/my-talk/slides/02.png" alt="The problem">
    The notes for the second slide…
  </Slide>
</ScrollSlides>
```

Pass `slidesOn="right"` to pin the deck on the right instead. See the full **["Exposing Weak Links in Multi-Agent Systems"](/posts/15062026_weaklinks/)** post for a live example.
