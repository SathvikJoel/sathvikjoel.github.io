This note is a living demo of the writing components available across the garden. **Delete it whenever you like** — it's just here so you can see the syntax and the result side by side.

## Sidenotes

Sidenotes float into the right margin on wide screens and collapse inline on mobile.<Sidenote n={1}>Like this — a margin note that doesn't break your reading flow. Resize the window to watch it move.</Sidenote> Use them for asides, citations, or definitions you don't want cluttering the main line.

```mdx
Some claim.<Sidenote n={1}>The aside goes here.</Sidenote>
```

## Years ago

I started this blog back in <Y y={2023} />, and first learned to code around <Y y={2019} />. The little superscript updates itself every year.

```mdx
back in <Y y={2023} />
```

## Wide image

A headline image can break out wider than the text column for impact. Make a collage PNG yourself and drop it in:

```mdx
<WideImage src="/collage.png" alt="" caption="..." />
```

## Reference callout

Cite an external article, paper, or link as a prominent card:

<Reference
  href="https://example.com"
  title="Revealed: How the UK tech secretary uses ChatGPT for policy advice"
  author="The Guardian"
  source="archive.is"
/>

```mdx
<Reference href="https://…" title="Headline" author="Author" source="Site" />
```
